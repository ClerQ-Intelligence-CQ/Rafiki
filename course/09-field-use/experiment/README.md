# Module 09 experiment: deployment checklist

## Objective

Apply the system to one real place instead of in the abstract.

## Steps

1. Pick a real place you know (clinic, farm, home, workshop).
2. Copy `checklist.md` to `checklist-<place>.md` and fill every row.
3. Name the failure-table row that would fire first there, with one
   paragraph of reasoning.
4. Estimate power: samples per second, duty ratio, daily energy order
   of magnitude.

## Expected outputs

- A filled checklist with no blank rows (write "unknown, must
  measure" where you cannot answer honestly).
- One named first-failure row with reasoning.
- A power estimate within an order of magnitude of the bench-derived
  numbers (tens of thousands of events/sec capacity vs ~100/sec need).

## Grading (self)

Full marks: every row answered, first-failure reasoned, power math
shown. Half marks: honest unknowns marked as unknowns. Zero: blank
rows presented as answers.
