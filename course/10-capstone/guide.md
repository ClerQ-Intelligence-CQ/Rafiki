# Module 10: capstone, your own regime (20 minutes)

Goal: prove you can use the whole system, not just read about it.

## The task

Design one synthetic regime the course never showed (night shift
worker, marathon training block, a week of travel, a broken sensor
that lies convincingly). Predict in writing what the twin will do:
which features move, which classes flip, whether anything fires,
what goes stale. Then run it and compare.

## Rules

1. Prediction first, in `report.md`, before running anything.
2. Implement the regime by editing a copy of the bench loop (never
   the engines).
3. Run, record every output line.
4. Score yourself with the rubric below. Be harsh; the rubric is.

## Rubric (10 points)

- Prediction written before running (2)
- Regime implemented without touching engine crates (2)
- All output lines recorded verbatim (2)
- Every mismatch between prediction and output explained (3)
- One genuine surprise documented (1)

## Report template

See `experiment/report-template.md`. Fill it, keep it to one page.
A good report is mostly mismatches explained, not victories listed.

## What this proves

Anyone can follow a guide. Designing a regime, predicting a twin,
and explaining the gap exercises every module at once. That is the
whole course in one sitting.
