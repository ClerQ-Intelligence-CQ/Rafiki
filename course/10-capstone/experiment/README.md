# Module 10 experiment: your regime

## Objective

Design, predict, run, explain. See `../guide.md` for rules.

## Steps

1. Write predictions in `report-template.md` (copy it first).
2. Copy one bench loop, implement your regime in the copy only.
3. Run. Paste outputs into the report.
4. Score yourself with the rubric. Be harsh.

## Expected outputs

A filled one-page report. There are no fixed expected numbers here;
the deliverable is the reasoning, especially where prediction and
output disagreed.
